API

    
Everything the UI does is available over HTTP. Interactive docs: /api/docs.

    

      
Authentication

      
Access to this app is controlled by Cloudflare Access. Scripts and the robot should use an
        Access service token and send CF-Access-Client-Id and CF-Access-Client-Secret.
        Your Cloudflare credentials go in two headers on every call. They are never stored by the server.

      

    

    

      

        
EndpointWhat it does

        
          
POST /api/solveMultipart image (+ layout, target, grid, model). Returns target, tiles and actions.

          
POST /api/preflightCheck that a model can read an image with your credentials.

          
GET /api/modelsCandidate vision models and the default.

          
POST /api/testsStart a run (JSON). Returns an id.

          
GET /api/tests/{id}/eventsServer-sent events: start, record, summary, end.

          
GET /api/tests/{id}Current state and records.

          
POST /api/tests/{id}/cancelStop a run, keeping partial results.

          
GET /api/tests/{id}/report.json · failed_runs.zipDownloads.

          
GET /api/healthLimits and allowed test hosts.
